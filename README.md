# Academic Website — Sheikh Badar Ud Din Tahir

A responsive, multi-page research website designed for GitHub Pages.

## Pages

- `index.html` — homepage, current research, selected publications, news and software.
- `research.html` — research descriptions and illustrative diagrams.
- `publications.html` — searchable/filterable bibliography.
- `cv.html` — printable academic CV overview.
- `assets/style.css` — design system and light/dark mode styles.
- `assets/script.js` — navigation, theme, publication filters and accessibility.
- `assets/publications.js` — **edit this file** to update paper information.

## Publish to GitHub Pages

1. Back up the existing site (especially your current `index.html`).
2. Open the GitHub repository for `https://sheikhbadar.github.io/` — usually `sheikhbadar/sheikhbadar.github.io`.
3. Upload the **contents** of this website folder to the repository root, preserving the `assets` folder, then commit.
4. In repository **Settings → Pages**, make sure the site deploys from the intended branch and folder.
5. After deployment, verify the homepage and the three subpages.

No framework, package installation, compilation or external JavaScript dependency is required.

## Existing Flag Counter preserved

The footer on every page uses the existing Flag Counter ID **`ZrS2`** and its original image URL. Do not regenerate this ID if you want to retain the accumulated counter data. The new design does not intentionally reset the count. How visits are counted or retained remains subject to Flag Counter's service.

## Before publishing — check factual details

- Verify every publication's authors, spelling, publication year, and manuscript status. The site separates *under review*, *preprint*, *journal article* and *conference proceedings*.
- The expected PhD completion date is **March 2027**, as supplied in your CV; update if it changes.
- The CFE–CMStatistics talk is labelled a **scheduled presentation** because its December 2026 date is in the future as of the site build.
- The `cv.html` page is a public-facing summary and does **not** publish referees' emails. Submit your official academic CV with referees separately for the ETH Zürich application.
- Research graphics are original **schematic illustrations**, not actual empirical results. Replace them with figures from your papers when suitable.
- No citation count is displayed because citation metrics need regular updates and source attribution.
- The manuscript listed as “under review” should be updated whenever the editorial status changes.
- Check whether your institute prefers the term “PhD Research Fellow” or “PhD Researcher” on the public website.
